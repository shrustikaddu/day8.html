StudyGenie AI 📚✨

StudyGenie AI is a beginner-friendly educational web application that helps students learn smarter by generating study notes and answering doubts instantly.

Features 🚀
Generate study notes for topics
Displays:
Summary
Key points
Quick quiz
Simple AI-style doubt answering system
Download notes as .txt file
Modern responsive UI with glassmorphism design
Technologies Used 💻
HTML5
CSS3
JavaScript
How It Works ⚡
Enter a study topic.
Click Generate Notes.
View generated summary, key points, and quiz.
Ask doubts in the doubt section.
Download notes using the download button.
